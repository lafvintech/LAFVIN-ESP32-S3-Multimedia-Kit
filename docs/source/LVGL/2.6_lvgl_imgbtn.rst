==================================
2.6 Image Buttons — Buzzer Control
==================================

Using images as clickable buttons to control the buzzer.

Overview
========

LVGL images can be made clickable by adding the ``LV_OBJ_FLAG_CLICKABLE`` flag. This project uses two image icons — a buzzer icon and a mute icon — as buttons to turn the buzzer on and off.

What You'll Learn
=================

* Making image objects clickable (alternative to ``lv_imgbtn``)
* Controlling the buzzer via GPIO (active high/low or PWM)
* Using image-based UI for a cleaner look

How the Code Works
==================

**Image Buttons**

Two C-array images (from ``image_data.h``) are created and made clickable:

.. code-block:: cpp

   lv_obj_t *btn_buzzer = lv_img_create(lv_scr_act());
   lv_img_set_src(btn_buzzer, &buzzer_icon);
   lv_obj_add_flag(btn_buzzer, LV_OBJ_FLAG_CLICKABLE);
   lv_obj_add_event_cb(btn_buzzer, buzzer_on_cb, LV_EVENT_CLICKED, NULL);

**Buzzer Control**

The buzzer on GPIO 45 supports two modes:

.. code-block:: cpp

   // Active buzzer (HIGH = ON)
   void buzzerOn()  { digitalWrite(45, HIGH); }
   void buzzerOff() { digitalWrite(45, LOW);  }

   // Passive buzzer (PWM tone)
   void buzzerOn()  { ledcWriteTone(0, 2000); }
   void buzzerOff() { ledcWriteTone(0, 0);    }

Expected Result
===============

- Two image icons: a buzzer (left side) and a mute symbol (right side)
- Tapping the buzzer icon turns the buzzer on continuously
- Tapping the mute icon turns it off

.. note::
   Check your hardware: if you have an active buzzer, it beeps at a fixed frequency. A passive buzzer requires PWM to produce sound.
