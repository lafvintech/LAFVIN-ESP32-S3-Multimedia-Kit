==============================
2.11 RGB LED Control Panel
==============================

An advanced WS2812 LED controller with color presets, brightness slider, and animation modes.

Overview
========

Building on the earlier RGB switch/checkbox project, this lesson creates a polished, single-purpose LED control panel. It adds features like a live color preview, brightness control, color presets, and animation effects.

What You'll Learn
=================

* Combining multiple widget types in one screen
* Building a color preview panel (custom object)
* Implementing LED animation patterns
* Using brightness scaling for WS2812

How the Code Works
==================

**Color Preview**

A circular object reflects the currently selected color in real time, just like the slider mixer from lesson :ref:`lvgl_slider`.

**Preset Color Buttons**

Six preset color buttons (Red, Green, Blue, Yellow, Cyan, Magenta) set predefined RGB values with a single tap.

**Brightness Slider**

A horizontal slider (0–100%) scales all RGB values proportionally before sending to the LED:

.. code-block:: cpp

   static void brightness_cb(lv_event_t *e) {
       int brightness = lv_slider_get_value(slider);
       int r = (selectedColor.r * brightness) / 100;
       int g = (selectedColor.g * brightness) / 100;
       int b = (selectedColor.b * brightness) / 100;
       neopixelWrite(48, r, g, b);
   }

**Animation Modes**

Four animation buttons trigger pre-programmed sequences:
- Color cycle (rainbow loop)
- Breathing effect (slow fade in/out)
- Strobe flash
- Smooth color transition

Expected Result
===============

A clean UI panel with:
- Live color preview circle
- Brightness slider (0–100%)
- 6 color preset buttons
- 4 animation mode buttons
- All changes reflect immediately on the WS2812 LED
