======================
2.1 LVGL Hello World
======================

Verifying that LVGL, the display, and the touch panel are all working correctly.

Overview
========

This is the simplest possible LVGL application: a single text label centered on screen. It confirms that:
- The TFT display is properly initialized and rendering
- LVGL's task handler is running
- The touch panel is detected

The ``Display`` Class
=====================

All LVGL projects share a common ``display.h`` / ``display.cpp`` pair that initializes:

* **TFT_eSPI** — SPI display driver for ILI9341 (320x240 landscape)
* **FT6336U** — I2C touch controller (SDA=2, SCL=1)
* **LVGL** — Graphics library core with display and touch drivers registered

.. code-block:: cpp

   #include "display.h"

   Display display;

   void setup() {
       Serial.begin(115200);
       display.init();  // Initialize display, touch, LVGL
       // ... create UI widgets ...
   }

   void loop() {
       display.routine();  // Call lv_timer_handler() at ~200Hz
   }

How the Code Works
==================

.. code-block:: cpp

   lv_obj_t *label = lv_label_create(lv_scr_act());
   lv_label_set_text(label,
       "TEST\n\n"
       "Hello World!\n\n"
       "Arduino LVGL");
   lv_obj_center(label);

A label widget is created on the active screen (``lv_scr_act()``), centered, with multi-line text using the built-in ``montserrat_20`` font. The background defaults to white.

What You'll Learn
=================

* How the shared ``Display`` class initializes the hardware
* Creating a basic LVGL label widget
* Centering and styling text

Expected Result
===============

After uploading, the TFT screen shows:

| **TEST**
| *Hello World!*
| *Arduino LVGL*

centered on a white background. Touch functionality is active but not used yet.
