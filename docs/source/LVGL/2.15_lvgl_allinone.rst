=============================
2.15 All-In-One Application
=============================

The capstone project: a smartphone-style app launcher that integrates every peripheral and UI module into one unified application.

Overview
========

This is the ultimate project tying everything together. It creates a home screen with scrollable pages of app icons, each launching one of the previous projects (Camera, Gallery, Music, Heartrate, RGB, Buzzer, WiFi, File Manager). It includes a status bar with WiFi indicator and real-time clock synced via NTP.

What You'll Learn
=================

* Building an app-launcher architecture with LVGL Tileview
* Lazy-loading: initializing modules only when needed
* Screen transition management (switching between apps)
* Properly stopping background tasks (camera, audio, sensor) when switching away
* NTP time synchronization for the clock
* Structuring a multi-module embedded application

Architecture
============

**Home Screen (Tileview)**

Two scrollable pages of app icons, each icon launching a different module:

.. code-block:: cpp

   lv_obj_t *tv = lv_tileview_create(lv_scr_act());

   // Page 1: Camera, Gallery, Music, Heartrate
   lv_obj_t *tile1 = lv_tileview_add_tile(tv, 0, 0, LV_DIR_LEFT);
   // Add icon buttons...

   // Page 2: RGB, Buzzer, WiFi, File Manager
   lv_obj_t *tile2 = lv_tileview_add_tile(tv, 0, 1, LV_DIR_RIGHT);
   // Add icon buttons...

**Lazy Initialization**

Each module is initialized only when the user taps its icon for the first time, saving memory:

.. code-block:: cpp

   static void launchCamera() {
       if (!cameraInitialized) {
           initCameraModule();
           cameraInitialized = true;
       }
       switchToScreen(cameraScreen);
   }

**Background Task Management**

When switching between apps, background tasks are properly stopped:

.. code-block:: cpp

   static void switchToScreen(lv_obj_t *newScreen) {
       // Stop current app's background tasks
       if (currentApp == CAMERA) cameraTaskStop();
       if (currentApp == AUDIO)  audio.stopSong();
       if (currentApp == HEARTRATE) sensorTaskStop();

       // Load new screen
       lv_scr_load(newScreen);
       currentApp = newApp;
   }

**Status Bar**

- Left: WiFi connection status indicator
- Right: Real-time clock (NTP-synced, CST-8 timezone: ``8 * 3600`` offset)

Expected Result
===============

#. The home screen shows two pages of app icons (swipe left/right to switch pages).

#. The status bar displays WiFi status and current time (synced via NTP once connected to Wi-Fi).

#. Tap any app icon to launch it. The app runs with its full functionality (camera, music, etc.).

#. Tap the back/home button in each app to return to the home screen.

This single sketch combines everything you've learned — display, touch, camera, SD card, audio, heart rate sensor, LEDs, buzzer, Wi-Fi, and file management — into one cohesive application.
