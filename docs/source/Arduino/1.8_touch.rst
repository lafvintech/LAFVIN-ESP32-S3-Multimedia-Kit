======================
1.8 Touch Panel
======================

Reading touch coordinates from the FT6336U capacitive touch controller via I2C.

Overview
========

This project introduces I2C communication by reading data from the FT6336U capacitive touch panel controller. You'll learn how to query register information from an I2C device and read real-time multi-touch coordinates.

What You'll Learn
=================

* I2C communication basics (SDA/SCL)
* Reading device registers over I2C
* Detecting touch gestures and multi-touch points

Pin Connections
===============

======= ========
FT6336U ESP32-S3
======= ========
SDA     GPIO 2
SCL     GPIO 1
======= ========

How the Code Works
==================

The sketch uses the **FT6336U** library to communicate with the touch controller. On startup, it dumps the chip's configuration registers:

.. code-block:: cpp

   FT6336U ft6336u(FT6336U_ADDR, &Wire);
   ft6336u.begin();

   Serial.print("Device Mode: ");
   Serial.println(ft6336u.readDeviceMode());

The main loop scans for touch points every 100ms, reading up to 2 simultaneous touch coordinates:

.. code-block:: cpp

   TouchPoint touch = ft6336u.scan();
   if (touch.status == TOUCH_DETECTED) {
       Serial.printf("Touch %d: (%d, %d)\n", touch.id, touch.x, touch.y);
   }

Expected Result
===============

Open the Serial Monitor (115200 baud). On startup, you'll see all the FT6336U register information. When you touch the screen, the coordinates of touch points are printed::

   Touch 1: (120, 180)
   Touch 1: (122, 178)
