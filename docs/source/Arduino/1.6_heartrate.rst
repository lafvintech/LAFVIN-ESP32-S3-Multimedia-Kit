========================
1.6 Heart Rate Sensor
========================

Read pulse data from the MAX30102 heart rate sensor and calculate BPM.

Overview
========

This example interfaces with the MAX30102 optical heart rate sensor over I2C. It reads infrared (IR) reflection data from your fingertip, detects individual heartbeats, and computes a rolling average of beats per minute (BPM).

What You'll Learn
=================

* Using I2C sensor libraries (SparkFun MAX3010x)
* Real-time sensor data processing
* Beat detection and BPM calculation with validation

Setup Notes
===========

Make sure you have already completed:

* :ref:`driver_install`
* :ref:`environment_setup`

Open the example sketch from the code package:

``LAFVIN-ESP32-S3-Multimedia-Kit-main/1.Arduino/6.HeartRate/6.HeartRate.ino``

This example uses the **onboard** MAX30102 sensor. No external wiring is required.

======== ========
Signal   ESP32-S3
======== ========
SDA      GPIO 2
SCL      GPIO 1
======== ========

Upload and Test
===============

#. Connect the board with a USB Type-C data cable.
#. Open ``6.HeartRate.ino`` in Arduino IDE.
#. In the **Tools** menu, select ``ESP32S3 Dev Module`` as the board and choose the correct serial port.
#. Click **Upload**.
#. Open **Serial Monitor** at ``115200`` baud. You should see::

      Initializing MAX30102...
      MAX30102 ready.
      Place your finger gently on the sensor and keep still.

#. Gently place your fingertip on the MAX30102 sensor (the small rectangular component with an LED window). After a few seconds, you should see BPM readings::

      Finger detected. Measuring heart rate...
      BPM=72.5, Avg BPM=73, IR(raw)=155000

.. note::
   Keep your finger still and apply gentle, consistent pressure. The sensor needs a few seconds to stabilize. If you see ``Signal too weak`` or ``No finger``, adjust your finger position.

How the Code Works
==================

**Sensor Initialization**

.. code-block:: cpp

   #include <Wire.h>
   #include "MAX30105.h"
   #include "heartRate.h"

   MAX30105 particleSensor;

   ParticleSensor.begin(Wire, I2C_SPEED_FAST);
   ParticleSensor.setup();  // Default config: IR LED only, Red LED off

**Finger Detection**

A debouncing algorithm with 8-sample hysteresis determines whether a finger is present:

.. code-block:: cpp

   const int FINGER_ON_THRESHOLD  = 12000;
   const int FINGER_OFF_THRESHOLD = 6000;

   long irValue = particleSensor.getIR();

   if (irValue > FINGER_ON_THRESHOLD) {
       fingerDetected = true;
   } else if (irValue < FINGER_OFF_THRESHOLD) {
       fingerDetected = false;
   }

**BPM Calculation**

.. code-block:: cpp

   if (checkForBeat(irValue)) {
       long delta = millis() - lastBeat;
       float bpm = 60000.0 / delta;

       // Validate: must be between 45–180 and within 25 BPM of average
       if (bpm > 45 && bpm < 180) {
           rates[rateSpot++] = (byte)bpm;
           rateSpot %= 8;   // 8-sample rolling window
       }

       lastBeat = millis();
   }

In the provided sketch:

* The red LED is disabled — only the IR LED is used for heart rate sensing
* BPM values outside 45–180 are discarded as noise
* BPM that deviates more than 25 from the running average is also rejected
* Readings are reported every 1000ms

Try This Next
=============

* Experiment with the ``FINGER_ON_THRESHOLD`` and ``FINGER_OFF_THRESHOLD`` values
* Increase ``RATE_SIZE`` from 8 to 16 for smoother averaging
* Graph the raw IR values in Arduino IDE's **Serial Plotter** (Tools > Serial Plotter) to visualise your pulse waveform
