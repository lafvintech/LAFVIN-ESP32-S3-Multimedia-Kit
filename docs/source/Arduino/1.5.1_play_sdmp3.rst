=================================
1.5.1 MP3 Playback from SD Card
=================================

Play MP3 audio files stored on a Micro SD card through the I2S audio amplifier.

Overview
========

This example combines the SD card and the I2S audio output to play MP3 music files. You'll mount the SD card, find an MP3 file, and stream its decoded audio to the MAX98357A amplifier that drives the onboard speaker.

What You'll Learn
=================

* Configuring I2S audio output pins with the ``Audio`` library
* Streaming MP3 data from an SD card to an I2S DAC
* Using ``audio.loop()`` to keep playback running

Setup Notes
===========

Make sure you have already completed:

* :ref:`driver_install`
* :ref:`environment_setup`

Open the example sketch from the code package:

``LAFVIN-ESP32-S3-Multimedia-Kit-main/1.Arduino/5.1_Play_SDMMC/5.1_Play_SDMMC.ino``

.. note::
   Before uploading, copy an MP3 file named ``test1.mp3`` to the ``/music/`` folder on your SD card.

=========== ========
Signal      ESP32-S3
=========== ========
SD CLK      GPIO 39
SD CMD      GPIO 38
SD D0       GPIO 40
I2S BCLK    GPIO 42
I2S LRC     GPIO 14
I2S DOUT    GPIO 41
=========== ========

Upload and Test
===============

#. Prepare a Micro SD card with an MP3 file at ``/music/test1.mp3``.
#. Insert the SD card, then connect the board with a USB Type-C data cable.
#. Open ``5.1_Play_SDMMC.ino`` in Arduino IDE.
#. In the **Tools** menu, select ``ESP32S3 Dev Module`` as the board and choose the correct serial port.
#. Click **Upload**.
#. Open **Serial Monitor** at ``115200`` baud. The audio track starts playing through the onboard speaker automatically. Metadata (if embedded in the MP3) is printed to the Serial Monitor.

How the Code Works
==================

**SD Card Mount**

.. code-block:: cpp

   #include "SD_MMC.h"

   SD_MMC.setPins(38, 39, 40);                 // CMD, CLK, D0
   SD_MMC.begin("/sdcard", true);              // 1-bit mode

**Audio Output Setup**

.. code-block:: cpp

   #include "Audio.h"

   Audio audio;
   audio.setPinout(42, 14, 41);  // BCLK, LRC, DOUT
   audio.setVolume(15);          // Range: 0 (mute) to 21 (max)

**Play MP3 from SD**

.. code-block:: cpp

   audio.connecttoFS(SD_MMC, "/music/test1.mp3");

**Audio Loop**

The ``audio.loop()`` call processes the audio pipeline — decoding MP3 frames and feeding I2S data. It must be called continuously in ``loop()``:

.. code-block:: cpp

   void loop() {
       audio.loop();
   }

In the provided sketch:

* The SD card is mounted in 1-bit SDMMC mode, matching the board's pinout
* The I2S pins are hard-wired to the MAX98357A on the board
* Volume 15 is a comfortable default level

Try This Next
=============

* Replace ``test1.mp3`` with your own MP3 files (keep the same file path)
* Change ``audio.setVolume(15)`` to a different value
* Combine with the SD card file listing in :ref:`arduino_sdmmc` to browse and play different tracks
