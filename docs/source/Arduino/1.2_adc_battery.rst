=======================
1.2 ADC Battery Monitor
=======================

Reading the battery voltage using the ESP32-S3's built-in ADC.

Overview
========

This project shows how to read an analog signal — the battery voltage — using the ESP32-S3's Analog-to-Digital Converter (ADC). The battery voltage is routed to GPIO 19 through a 1:4 voltage divider, so the ADC sees at most 1/4 of the actual battery voltage.

What You'll Learn
=================

* Using ``analogRead()`` on the ESP32
* Configuring ADC attenuation with ``analogSetAttenuation()``
* Converting raw ADC values to real voltage

Pin Connections
===============

============ ========
Battery      ESP32-S3
============ ========
V_BAT (1/4)  GPIO 19
============ ========

How the Code Works
==================

.. code-block:: cpp

   analogSetAttenuation(ADC_11db);  // Full range: 0–3.3V

   int raw = analogRead(19);
   float voltage_at_pin = (raw / 4095.0) * 3.3;  // ESP32-S3 ADC is 12-bit
   float battery_voltage = voltage_at_pin * 4.0;  // Compensate divider

The code reads the ADC every 200ms and prints the raw value, pin voltage, and actual battery voltage to the Serial Monitor.

Expected Result
===============

Open the Serial Monitor (115200 baud). You should see readings similar to::

   ADC Raw: 2450  Pin Voltage: 1.97V  Battery Voltage: 7.88V
   ADC Raw: 2448  Pin Voltage: 1.97V  Battery Voltage: 7.88V

.. note::
   The actual value depends on your battery's charge level. A fully charged 2-cell Li-ion battery (8.4V) will read approximately 8.2V–8.4V.
